# 指标注册中心 (Metric Registry)

## 1. 设计目标

让 **178 个指标长期可维护**：
- **看得见**：所有指标、Owner、口径、SLA、调用量、谁在用，集中可查
- **改得了**：变更走审批流，自动出影响分析，灰度上线
- **算得稳**：实时数据质量监控、SLA 告警、版本回滚

## 2. 用户角色

| 角色 | 主要操作 |
|------|---------|
| **指标 Owner** | 创建/修改/废弃自己负责的指标; 审批与自己相关的下游变更 |
| **数据 Steward** | 配置 fact / formula / etl; 处理质量事件 |
| **Approver (CFO/合规)** | 高敏感指标 + 跨部门变更的审批 |
| **Viewer / Subscriber** | 浏览; 订阅指标变更; 看 SLA 历史 |
| **平台 Admin** | 角色管理 / 标签体系 / SLA 默认值 |

## 3. 页面架构

```
/metric-registry/
├─ /                     首页 (概览: 指标数/Owner 分布/SLA 健康度/Top 调用)
├─ /list                 指标列表 (搜索/筛选/批量操作)
├─ /detail/:code         指标详情 (口径/SQL 预览/历史/订阅/影响)
├─ /editor[/:code]       新增/编辑 (走变更申请)
├─ /requests             变更申请列表 (草稿/待审批/已合并)
├─ /requests/:id         变更详情 (Diff + 影响分析 + 审批)
├─ /quality              数据质量看板
├─ /lineage              指标血缘图谱
├─ /subscriptions        我订阅的指标
└─ /settings             角色 / 标签 / SLA 默认值
```

## 5. 关键交互

- **指标搜索**：标题/编号/同义词/Owner/标签全文检索 + 拼音 + 模糊
- **批量操作**：批量 Owner 变更（如人事变动）、批量打标、批量订阅
- **YAML 编辑**：支持直接编辑 YAML（高级模式），自动 jsonschema 校验
- **Git 双向同步**：注册中心修改自动 PR 到 `metrics/*.yaml`；YAML 文件改动经 CI 校验后自动入库
- **试算沙箱**：编辑时点击"运行"在影子环境跑示例，给出预估扫描行数与耗时
- **暗黑模式**：减少财务夜间使用疲劳
