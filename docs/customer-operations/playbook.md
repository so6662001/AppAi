# 客户运营手册

## 客户生命周期

```
试用 (Trial)
  ↓ 7天免费 / 50 万 Token 体验包
首次付费 (Paid)
  ↓ 月度活跃 (DAU / 周问答次数 / 卡片点击率)
扩展 (Expansion)
  ↓ 增加用户席位 / 升级套餐 / 增加业务模块
续费 (Renewal)
  ↓ 续约价格 / 折扣
流失召回 (Churn)
  ↓ 主动联系 / 临时降价 / 客户成功经理介入
```

## 关键运营指标 (DAU/MAU)

- 早报打开率 (首屏 7s 曝光)
- 卡片点击率 (尤其 ADVICE 类目)
- 建议采纳率 (acted / shown)
- AI 问答 NPS (👍 / 👎 比例)
- 套餐到期前 30 天续费率
- Token 月度消耗增长率

## 试用流程

1. **官网填表** → 销售触达
2. **客户成功经理 (CSM) 引导**: 30 分钟 onboarding 会议
3. **数据接入** (1~2 周): SeaTunnel 拉客户业务库
4. **角色 + 模板订阅** (1 天): 老板/业务员/厂长各订几个模板报表
5. **跑 1 周** 观察使用情况
6. **决定付费**

## 套餐推荐策略

- **小厂 (TRADE, 10~50 人)**: Token 100W ¥299 试用 → Token 500W ¥1,299
- **中型 (PROCESS, 50~200 人)**: Pro 月订阅 ¥1,999/月
- **大型钢厂 (MILL, 500+ 人)**: 企业版年付 ¥99,000 + 私有化部署

## 续约谈判

- 续约提前 60 天通知
- 续费率 < 80%: CSM 介入做客户访谈
- 涨价: 老客户保护价 (首年价 × 1.05)

## 流失召回

- 月活下降 50% → CSM 主动电话
- 余额耗尽不续费 → 提供 15% 折扣 + 7 天宽限期
- 已流失 → 季度回访邮件 + 新功能简报

## 公开数据

- 行业报告 (匿名汇总)
- 客户案例 (CFO/厂长 video testimonial)
- 钢铁 AI 经营年度白皮书

- 企业微信社群 (售后)
